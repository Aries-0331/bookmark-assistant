# Support

Bookmark Assistant has two support paths.

## Community Support

For open source and self-hosted usage:

- Open a GitHub issue for reproducible bugs.
- Use discussions or issues for setup questions.
- Include package versions, browser version, logs, and reproduction steps.

Community support is best-effort.

## Official Cloud Support

Paid Pro customers using the official hosted service receive priority support for:

- Billing and subscription issues.
- Hosted API availability.
- Account and Notion OAuth issues.
- Product behavior that differs from the documented Pro plan.

Contact:

`aries0331.dev@gmail.com`

## Self-Hosted Scope

Self-hosted deployments are your responsibility. The project provides source code and setup documentation, but does not operate or monitor your infrastructure.
