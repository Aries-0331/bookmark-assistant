## Reading Order

1. Start with the [Project README](../README.md).
2. Use [Self-Hosting](../SELF_HOSTING.md) if you want to run your own instance.
3. Read [State Management](STATE_MANAGEMENT.md) before changing extension UI or background state.
4. Read [Notion Integration](NOTION_INTEGRATION.md) before changing OAuth or sync behavior.
5. Read [Contributing](../CONTRIBUTING.md) before opening a pull request.

## Public Documentation Policy

Keep this repository focused on reusable product, architecture, API, self-hosting, contribution, and security documentation.

Do not add private launch checklists, production credentials, store submission notes, internal support drafts, unpublished roadmap plans, or agent-specific implementation plans to the public docs tree.
